# Blind answer check

The input file lists numbered multiple-choice questions (Pakistan Military Academy initial test: general knowledge, Pakistan studies, Islamiat, current affairs, English, maths and intelligence puzzles). The answers are NOT given. Solve every question yourself, independently.

- Maths, series, percentages, days, directions: work them out step by step.
- Facts: answer from reliable knowledge. Questions about who currently holds an office, records, rankings, recent events or anything that may have changed must be answered as of TODAY (October 2026): use WebSearch for those (it is a deferred tool: first call ToolSearch with query `select:WebSearch`). Also search when you are not sure.
- If a question is flawed (no option is correct, two options are correct, the question is ambiguous or outdated), answer X and say why in the note.

Write the output file (path given in your assignment), one line per question, in this exact format:

<number>: <letter A-E or X> | <high|medium|low> | <short note, only when useful>

Example lines:
1712: B | high |
1713: X | medium | two options correct: both Lahore and Karachi fit
Do not skip any number. Reply only with the output path and the number of lines written.
